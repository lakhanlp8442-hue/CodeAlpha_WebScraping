# CodeAlpha - Task 1: Web Scraping

## Project Overview
This project is completed as part of the CodeAlpha Data Analytics Internship. It extracts book catalog data (Title, Price, Rating, and Stock Availability) from public pages using Python's `requests` and `BeautifulSoup` libraries, and exports the final dataset into a structured CSV file.

## Tech Stack
- Python 3.x
- Libraries: BeautifulSoup4, Requests, Pandas

## Files Included
- `scraper.py`: Main Python script for web scraping.
- `scraped_books_dataset.csv`: Extracted structured dataset.
- `requirements.txt`: Required dependencies.
